Sign in

Connect a GitHub token to create, edit, and delete posts in the site repository.

Token setup
  1. Open New fine-grained token.
  2. Token name: seufert.co editor. Expiration: choose the longest option you are comfortable with.
  3. Resource owner: blakeseufert. Repository access: Only select repositories, then choose seufert.co.
  4. Repository permissions: set Contents to Read and write. Leave everything else at the default; Metadata stays read-only automatically.
  5. Generate the token, paste it here, and connect. GitHub only shows the token once.

The editor stores the token only in this browser until you sign out. If it expires or is lost, create a new one from Personal access tokens.

Shortcut: open /editor/#token=github_pat_... once. The editor saves it locally and removes it from the URL.
